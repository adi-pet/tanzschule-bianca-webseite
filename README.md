# Tanzschule Bianca – Musterwebseite

Moderne statische Musterwebseite für die digitale Neuausrichtung der Tanzschule Bianca Fackler.

## Inhalt

- `index.html` – einseitige Musterwebseite
- `assets/real/` – echtes Bildmaterial aus der bestehenden Website als Arbeitskopie
- `assets/ai/` – klar gekennzeichnete AI-Entwurfsbilder für Moodboards und Kampagnen

## Lokal ansehen

```bash
python -m http.server 8080
```

Dann im Browser öffnen: `http://localhost:8080/`

## Hinweis

Vor Veröffentlichung bitte Bildrechte, Einwilligungen, Impressum, Datenschutz und finale Kontaktdaten prüfen.
